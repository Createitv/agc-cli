# @createitv/agc-cli

Install the AppGallery Connect CLI from npm:

```bash
npm install --global @createitv/agc-cli
agc version
```

The package contains the official release binaries for macOS (x64/arm64), Linux
(x64/arm64), and Windows (x64). It has no install-time scripts and makes no
additional network request after npm downloads the package, which makes it
suitable for unattended CI and internal npm mirrors.

Project documentation: <https://github.com/Createitv/agc-cli>
